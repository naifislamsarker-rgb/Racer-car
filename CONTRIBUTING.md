# Contributing to Racer Car

Thanks for your interest in improving Racer Car! 🏎️

## Ways to contribute

- Report bugs
- Suggest new features
- Improve documentation
- Submit code fixes or new features

## Getting started

1. Fork the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/<your-username>/Racer-car.git
   cd Racer-car
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Copy `.env.example` to `.env.local` and add your own values
5. Start the dev server:
   ```bash
   npm run dev
   ```

## Making changes

1. Create a branch: `git checkout -b feature/short-description`
2. Make your changes and test them in the browser
3. Commit with a clear message: `git commit -m "Add nitro power-up"`
4. Push: `git push origin feature/short-description`
5. Open a Pull Request describing what you changed and why

## Guidelines

- Keep pull requests small and focused
- Match the existing code style
- Never commit API keys or `.env` files
- Be kind and respectful to other contributors

## Reporting bugs

Open an issue using the bug report template and include steps to reproduce, what you expected, and what happened. Mention your browser and device.
